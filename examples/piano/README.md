# Example MIDI files

| file | source | license |
|---|---|---|
| `clair_de_lune.mid` | Debussy, Suite bergamasque: Clair de Lune (Mutopia Project) | Public Domain |
| `KV331_3_RondoAllaTurca.mid` | Mozart, Sonata K. 331, 3rd movement (Mutopia Project) | Public Domain |
| `brahms_intermezzo_op118_no2.mid` | Brahms, Intermezzo Op. 118 No. 2 (Mutopia Project) | Public Domain |
| `rach_prelude_op3_no2.mid` | Rachmaninoff, Prelude in C# minor Op. 3 No. 2 (Mutopia Project) | CC BY-SA 4.0 |
| `knights_suite.mid` | Built by `blockout/suite.py`: an original theme plus excerpts of the Rachmaninoff and the Brahms above | CC BY-SA 4.0 (contains the Rachmaninoff excerpt) |

`*.feeling.json` are performance charts for `blockout/feeling.py` (our own reading of the scores), MIT like the code.

The sampled piano used by `blockout/sampler.py` (Salamander Grand Piano V3, CC-BY 3.0, Alexander Holm) is **not** included; see the main README for the download link.
