# Example drum MIDI

| file | source | license |
|---|---|---|
| `rock_groove.mid` | Original 16-bar rock groove, written by `blockout/drum_groove.py` (`python -m blockout.drum_groove examples/drums/rock_groove.mid`): hi-hat groove, ride verse with ghost notes and pedal chicks, open-hat lifts, a fill round the kit, crash chorus. General MIDI drums, channel 10, 112 bpm. | MIT, like the code |
| `technique_groove.mid` | Original 9-bar technique study, written by `blockout/drum_groove.py` (`python -m blockout.drum_groove examples/drums/technique_groove.mid --song technique --bpm 104`): side-stick backbeats, ride bell, a flam, ghost notes, two crash chokes into stops, rimshot backbeats, a third choke, a ringing final crash. Each bar gives `blockout/drum_teacher.py` one technique to find. General MIDI drums, channel 10, 104 bpm. | MIT, like the code |
